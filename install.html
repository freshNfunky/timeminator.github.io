Installation Guide

Download & Extract

Get the latest release from GitHub and extract the archive to your web server.

  • Requires PHP 8.1+
  • MySQL or SQLite database
  • Web server (Apache, Nginx, etc.)

Run Web Installer

Open your browser to the installation URL and follow the guided setup.

  • Database configuration
  • Admin account creation
  • Base URL settings

Configure Projects

Create your projects and define custom time tracking categories.

  • Add team members
  • Set project budgets
  • Define categories

Start Tracking

Your team can immediately start tracking time and logging sentiment data.

  • Live timer or manual logs
  • Monthly sentiment ratings
  • Budget vs. actual reports
